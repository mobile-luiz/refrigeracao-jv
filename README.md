# Climaximo Refrigeração e Climatização

Site da Climaximo: instalação, manutenção preventiva e higienização de ar-condicionado.

## Arquivos

Todos os arquivos ficam na mesma pasta (raiz do repositório):

- `index.html`: página do site
- `style.css`: estilos (cores, layout, celular)
- `script.js`: botões do WhatsApp, menu do celular e configurações
- `*.jpg`: fotos
- `logo-horizontal.svg` / `logo-horizontal-branca.svg` / `icone-branco.svg`: logo
- `favicon.svg` / `favicon-32.png` / `apple-touch-icon.png`: ícone da aba e do celular

## Configuração

No começo do `script.js`:

```js
const WHATSAPP = "558189484064";
const INSTAGRAM = "https://www.instagram.com/refrigeracaojv";
```

## Publicar no GitHub Pages

Settings → Pages → Branch: `main`, pasta `/ (root)` → Save.
